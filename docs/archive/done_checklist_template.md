# Done checklist (per patch)

- [ ] Unit tests added/updated and passing
- [ ] Sanity doc under `docs/sanity/patch_*.md` filled with commands and expected outcomes
- [ ] CHANGELOG entry added
- [ ] No breaking API change without versioning (or documented)
- [ ] Feature flags used if risky (e.g. SNAPSHOT_FIELDS_ENABLED)
- [ ] Rollback steps documented (env disable, revert commit)
