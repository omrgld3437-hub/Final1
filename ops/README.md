# ops — Çalıştırma scriptleri

**Konum:** `ops/`  
**Güncelleme:** 2026-05-23 (otomatik: `python3 scripts/devops/generate_folder_readmes.py`)

## Ne işe yarar?

Manager, Web, Worker ve marketing sitesini başlatma/durdurma/deploy.

## Bu klasörde ne bulursunuz?

Kökteki `start.command` / `stop.command` doğrudan çalıştırılabilir; `ops/` altında aynı mantığın kopyaları da vardır.

## Önemli dosyalar

start.command · stop.command · deploy.sh · run.sh · *.bat
