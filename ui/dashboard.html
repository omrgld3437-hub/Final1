Şifre Değiştirme Zorunlu

Admin tarafından oluşturulan şifre tek kullanımlıktır.

Güvenliğiniz için lütfen yeni bir şifre oluşturun. Yeni şifrenizi asla sizden başkası göremez. Şifre değiştirmeden başka işlem yapamazsınız.

Şifre şartları:
  • En az 10 karakter
  • En az 1 büyük harf, 1 küçük harf, 1 rakam
  • En az 1 noktalama işareti (.,!?;:)
  • İsim/soyad içeremez; şifreler aynı olmalıdır.

API Key ve Secret Gerekli

Binance API Key ve Secret'inizi girmeniz zorunludur.

Binance'den API Key Nasıl Alınır?

  1. Binance hesabınıza giriş yapın
  2. Sol üst köşedeki profil ikonuna tıklayın
  3. "API Management" veya "API Yönetimi" seçeneğine gidin
  4. "Create API" veya "API Oluştur" butonuna tıklayın
  5. API adı verin (örn: "Trader Trailing")
  6. API Key ve Secret Key'i kopyalayın
  7. Önemli: Secret Key'i sadece bir kez görebilirsiniz, mutlaka kaydedin!
  8. IP kısıtlaması ekleyin (Ayarlar sekmesinden sunucu IP adresini kopyalayıp Binance'ye yapıştırın)
  9. API izinlerini "Enable Reading" ve "Enable Spot & Margin Trading" olarak ayarlayın

Güvenlik

Platformumuz para çekme yetkisine sahip değildir. Binance, üçüncü taraf API'lere varsayılan olarak para çekme izni vermez; siz açıkça vermediğiniz sürece varlıklarınız yalnızca okuma ve spot işlem ile sınırlı kalır.

API oluştururken "Enable Withdrawals" / "Para çekmeyi etkinleştir" seçeneğini kesinlikle işaretlemeyin. Yalnızca "Enable Reading" ve "Enable Spot & Margin Trading" yeterlidir. Bu sayede sistem alım-satım işlemlerinizi yürütebilir; para çekme yetkisi yalnızca sizin kontrolünüzde kalır.

API Key ve Secret'i girdikten sonra sisteminiz tam olarak çalışacaktır.
